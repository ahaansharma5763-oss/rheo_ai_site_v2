Twelve things happen before a single email leaves.

This is the part nobody sees, and it decides whether anything after it works.

  1. We agree who you want and who signs there.
  2. We set up separate web addresses like yours. Your main email is never used.
  3. We sign each one with SPF, DKIM and DMARC, so mail providers can tell it is really you.
  4. We warm each inbox up for three weeks, a few emails a day at first.
  5. We list the companies that fit, from maps, directories, web search and professional networks.
  6. An AI agent reads each company's website and removes the ones that don't fit.
  7. We remove any company that publicly shows it is already your customer. We never ask for your list.
  8. We merge companies that appear under two web addresses, so one company does not get two first emails.
  9. We look for a dated, public reason to write, and check it is still true.
  10. We find the person who signs, mostly from public pages, and note why it is them.
  11. We check the address is real. That only proves the mailbox exists, so we also check the person still holds the role.
  12. An AI agent drafts the opening line from the source. A line with no source is dropped.

Every morning we decide who deserves an email.

Most tools send whatever is next on the list. When follow-ups use up the day's limit, new companies stop hearing from you, and replies dry up soon after. So every morning we count the first emails that will go out, and read the limits back to check they saved.

  1. 1Companies with a fresh reason, strongest first.
  2. 2Follow-ups that are due.
  3. 3Other companies that fit, each with something specific to say.
  4. 4Room left over stays unsent.

We would rather send nothing than send something with no point.
